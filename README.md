## Реалізовані задачі CI/CD
Виконано такі завдання:

1. **Автоматичне тестування:** Використання `Pytest` для перевірки бізнес-логіки.
2. **Перевірка стилю коду (Linting):** Використання сучасного лінтера `Ruff` для дотримання стандартів PEP8.
3. **Мультиверсійне тестування:** Перевірка сумісності коду на версіях Python **3.10, 3.11, 3.12 та 3.13**.
4. **Збірка Docker-контейнера:** Автоматичне створення Docker-образу на базі `Dockerfile`.
5. **Автоматичний HTML-звіт:** Генерація візуального звіту про проходження тестів та збереження його як артефакту (`pytest-html`).
